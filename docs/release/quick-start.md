# Episteme 快速开始（0.3.0 RC）

Episteme 是一个学习工作台：你把课程材料放进来，就材料提问，回答里的每一句都标明出处。你可以把自己的理解保存下来，下次学习时它会被重新找出来。只有你自己确认过的内容才算你的理解，AI 只能提议。

## 运行环境

- **系统**：Windows 10 或 11，64 位。
- **其他软件**：不需要另外安装。Node.js、Episteme 内核和数据库驱动都已经打包在安装程序里。
- **网络**：要用真实模型回答问题时需要联网，并且要有一个 OpenAI 兼容服务的地址和密钥（例如 DeepSeek，或你自己的网关）。没有配置模型时，程序也能打开，但只会从材料里摘录原句，不会真正回答。
- **端口**：程序在本机使用 4324 端口，只监听 127.0.0.1，局域网里的其他电脑访问不到。

## 安装

1. 双击 `Episteme_0.3.0-rc1_x64-setup.exe`。
2. Windows 可能会弹出"Windows 已保护你的电脑"，因为这个安装程序没有代码签名。点 **更多信息 → 仍要运行**。
3. 安装程序只装给当前用户，不需要管理员权限。装完后，开始菜单和桌面上会出现 **Episteme**。

## 第一次打开

1. 打开 Episteme。第一次启动要等几秒，窗口会先显示"正在启动 Episteme"。
2. **设置模型**：点左下角的 **模型**。
   - 填三项：服务地址、模型名、密钥。用 DeepSeek 的话，点上方的 **DeepSeek** 就能自动填好地址和模型名，只需要自己填密钥。
   - 点 **保存**。程序会先试着连一次，地址或密钥不对时会直接告诉你，错误的设置不会被保存。
3. **建一个空间**：在左侧"新空间的名字"里输入课程名，比如"线性代数"，点 **新建**。
4. **放入材料**：点空间下面的 **材料 → 上传材料**。支持 PDF、Markdown 和纯文本。扫描版 PDF 里没有文字，放进来也读不出内容。

## 学习，并保存自己的理解

1. 点左上角的 **开始新对话**，在底部输入框提一个关于材料的问题，按回车。
2. 回答里的小数字（例如 `1`）是引用。点一下，右边会打开原文，并高亮那一段话。
3. 想把一个结论记下来，有两种方式：
   - 点回答下面的 **提炼成待确认的理解**，程序会提出一条候选。
   - 在你自己说过的话旁边点 **这是我的理解**。
4. 候选会出现在右侧"理解层"的 **等你确认** 里。你可以点 **确认为我的理解**，或者点 **改一改**，按你自己的说法改好后 **保存为我的理解**，也可以点 **不要**。只有你确认过的才会保存成你的理解。
5. 确认之后，它会出现在 **你已确认** 和左侧的 **我的理解** 里。点开能看到它的原话、来源对话和修改记录。

## 下次学习时找回你的理解

- 关掉窗口后，程序会留在任务栏右下角的托盘里继续运行。要真正退出，在托盘图标上右键选 **退出 Episteme**。
- 下次打开时，空间、材料、对话和理解都还在。
- 在同一个空间里开新对话、问相关的问题时，回答下面会出现一块 **"你之前确认过（不是材料，只是提醒）"**，列出相关的理解。点它可以打开那条理解，再点 **回到当时的对话**，就能回到你当时说这句话的地方。
- 这些理解来自你之前保存的数据，不是模型临时编出来的。它们和材料引用分开显示，也不会被当作依据来标注编号。

## 数据放在哪里

所有内容都在一个文件夹里：

```
%APPDATA%\club.sair.mindlink\
  mindlink.db        你的空间、材料、对话和理解
  model.json         模型设置，包括密钥（明文保存在本机，请不要把这个文件发给别人）
  agents.json        接入的 Agent 设置
  logs\service.log   服务日志，出问题时用
```

在托盘图标上右键选 **打开数据文件夹**，就能直接打开它。文件夹和数据文件名里的 `mindlink` 是代码仓库的名字，保持不变，这样升级后还能找到原来的数据。

- **备份**：先从托盘退出 Episteme，再复制 `mindlink.db`。
- **升级**：直接运行新版本的安装程序。数据文件夹不受影响。
- **卸载**：在 Windows"设置 → 应用"里卸载。卸载不会删除数据文件夹；要彻底清除，就手动删掉这个文件夹。

## 出问题时

| 现象 | 处理 |
|---|---|
| 窗口显示"Episteme 没能启动"，并提到端口 4324 被占用 | 关掉占用这个端口的程序。如果是另一个 Episteme 还在托盘里，先退出它，再重新打开。 |
| 窗口显示"服务启动后退出了" | 页面上会显示日志的最后几行和日志位置。把 `logs\service.log` 发给维护者。 |
| 提问后提示"现在用的是模拟模型" | 还没有设置模型，按"第一次打开"第 2 步设置。 |
| 提问后提示模型拒绝了凭据或超时 | 到 **模型** 页重新填写密钥，或者检查网络。你的问题会保留，可以点 **重试**。 |
| 上传 PDF 后搜不到内容 | 这个 PDF 可能是扫描图片，没有文字层。换成带文字的版本。 |

## 已知局限（RC）

- 只有 Windows 64 位安装包，没有代码签名。
- 同一时间只能运行一个 Episteme。
- 理解层目前是列表形式，图谱视图在"我的理解"页里。
- 进入一个空间时，先显示这个空间的概览页，要点 **学习** 或某个对话才能进入对话。
