| P1 | 安装包没有代码签名 | Windows SmartScreen 会拦一下 | 点"更多信息 → 仍要运行"（快速开始里写了） |
| P2 | 进入一个空间时先显示概览页，不是直接进入对话 | 多点一次 | 点"学习"或左侧的某个对话 |
