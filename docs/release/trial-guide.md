# MindLink 真人试用流程（15–30 分钟）

试用对象：没有参与开发的本科生，用自己手上正在学的课程材料。

要回答的问题：**这位同学能不能独立地用 MindLink 保存自己的理解，并在下次学习时把它找回来、再用上？**

## 试用前（主持人准备）

- 一台 Windows 10/11 电脑，把 `MindLink_0.3.0-rc1_x64-setup.exe` 放在桌面上。
- 一个可用的模型服务地址、模型名和密钥。让试用者自己输入，或者由主持人当面输入。不要把密钥写在纸上或聊天里。
- 试用者自己的学习材料：一份带文字的 PDF 或笔记，10 页以内最好。
- 主持人只观察，不指点。试用者卡住超过 2 分钟时，可以给一句提示，并在记录里写明。
- 把 [快速开始](quick-start.md) 发给试用者，但不要求他提前读。

## 任务（读给试用者听，一次读一条）

| # | 任务 | 计时 |
|---|---|---|
| 1 | 安装并打开 MindLink。 | |
| 2 | 设置模型，让它能真正回答问题。 | |
| 3 | 为你正在学的这门课建一个空间。 | |
| 4 | 把你带来的材料放进去。 | |
| 5 | 就材料问一个你真正想知道的问题，看看回答依据的是材料里的哪一段。 | |
| 6 | 把你从这次问答里得到的一条理解保存下来，用你自己认可的说法。 | |
| 7 | 彻底关闭 MindLink（包括托盘里的），再重新打开。 | |
| 8 | 找到你刚才保存的那条理解。 | |
| 9 | 开一个新对话，问一个和它相关的问题，看看 MindLink 有没有用上你之前的理解。 | |

## 结束后的 4 个问题

1. 你觉得"保存理解"和"让 AI 总结"有什么不同？这个不同对你有没有用？
2. 第 9 步里，MindLink 找回的那条理解对你有帮助吗？
3. 哪一步最让你困惑？
4. 你下周还会用它学这门课吗？为什么？（1–5 分）

## 判定

- **通过**：第 6、8、9 步都是独立完成，或者只给了一次提示。
- **不通过**：第 6、8、9 步中有任何一步没有完成。记下卡住的具体位置，作为下一版的 P0。

试用结果只记录真实发生的情况。没有真人试用时，交付报告里写"已交付试用包，真人试用待完成"。
