### agent

贝叶斯这一章可以分成四块：

1. 条件概率：一件事发生时另一件事的概率（你已经会）
2. 全概率公式：把一个概率按情况拆开再加起来，是贝叶斯分母的来源
3. 贝叶斯定理：用先验和似然算后验（同课很多同学卡在"似然不是概率分布"这里）
4. 共轭先验：让后验算得出来的一类先验，考试只考最简单的一种

关系：1 和 2 是 3 的前提；4 是 3 的计算技巧。你的目标是计算题，所以 2、3 必学，4 学到能用就行。建议从 2 开始，因为它是你缺的前置知识。从这里开始可以吗？
