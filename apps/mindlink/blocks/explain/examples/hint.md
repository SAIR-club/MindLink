### agent

一个工厂两条产线：甲线出 60% 的产品、次品率 2%；乙线出 40%、次品率 5%。随手拿一件，它是次品的概率怎么算？

### learner

0.02 加 0.05？

### agent

线索：甲线的产品只占六成，它的次品率在总数里该占多大分量？

### learner

那是 0.6×0.02 + 0.4×0.05，等于 0.032。

### agent

对。你刚才自己得出的就是全概率公式：P(A) = Σ P(A|Bi)·P(Bi)，"按情况拆开、按比例加权"是你说出来的。用两三句话复述一下这个公式？

### learner

把所有情况分开，每种情况下的概率乘上这种情况出现的概率，再加起来。

### agent

复述没有问题。
