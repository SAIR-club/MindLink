# 复述检查

## 通用

1. 请学习者用自己的话把刚才的要点讲一遍，不超过三句话；说明"不用照抄，说错了也没关系"。
2. 等学习者复述完，再对照刚才讲过的内容，找出三类问题：说错的、漏掉的关键条件、只复述了字面而没说出为什么的。
3. 每次只处理最重要的**一个**问题，按当前强度回应；学习者改过之后再看下一个，最多三轮。
4. 学习者的复述原话留在对话里，不要改写成你的话；之后的总结蒸馏要引用原话。

复述基本正确时，用一句话说出它好在哪里，然后结束，不要为了检查而挑刺。

## hint

指出有问题的是哪一句、属于哪一类问题（说错、漏条件、没说为什么），请学习者自己改正；不给出正确的说法。

## ask

用一个反问让学习者自己发现问题，例如"如果数据只有一条，你这句话还成立吗？"；不指出是哪一句，也不说出正确的说法。学习者连续两轮没发现，就问学习者要不要换成给提示。

## tell

直接指出错或漏的地方，并给出正确的说法，再请学习者用自己的话把改过的那一句重说一遍。

## 结束条件

学习者的复述没有明显的错误和遗漏；或者已经做满三轮；或者学习者表示不想再复述。
